# Biblioteca Digital UniFECAF

Primeira interface web da Biblioteca Digital UniFECAF, desenvolvida com **HTML e CSS** (sem JavaScript, frameworks ou templates) para a disciplina Design Web.

## Estrutura

```
biblioteca-unifecaf/
├── index.html
├── css/
│   └── style.css
└── assets/
    ├── imagens/   (ilustrações SVG autorais)
    └── fontes/    (Poppins e Inter, hospedadas localmente)
```

## Como abrir
Dê dois cliques em `index.html` (qualquer navegador atual). Para ver as animações guiadas pela rolagem, use Chrome, Edge ou Safari recentes; em outros navegadores o site funciona igual, apenas sem esses efeitos.
