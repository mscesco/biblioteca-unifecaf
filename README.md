# Biblioteca Digital UniFECAF

Primeira interface web da Biblioteca Digital UniFECAF, desenvolvida com **HTML e CSS** (sem JavaScript, frameworks ou templates) para a disciplina Design Web.

## Estrutura

```
biblioteca-unifecaf/
├── index.html
├── css/
│   └── style.css
└── assets/
    ├── imagens/   (ilustrações SVG autorais)
    └── fontes/    (Poppins e Inter, hospedadas localmente)
```

## Como abrir
Dê dois cliques em `index.html` (qualquer navegador atual). Para ver as animações guiadas pela rolagem, use Chrome, Edge ou Safari recentes; em outros navegadores o site funciona igual, apenas sem esses efeitos.

## Como publicar (GitHub Pages)
1. Crie um repositório público e envie todos os arquivos desta pasta (o `index.html` deve ficar na raiz).
2. No repositório: **Settings → Pages → Build and deployment → Deploy from a branch**.
3. Escolha a branch `main` e a pasta `/ (root)` e salve. Em alguns minutos o link público aparece na mesma tela.

## Como publicar (Netlify)
Acesse app.netlify.com/drop e arraste a pasta `biblioteca-unifecaf` inteira.

## Antes de entregar
- Troque o e-mail de exemplo (`biblioteca@exemplo.com.br`) na seção Contatos, em `index.html`.
- Textos e ilustrações são demonstrativos; as capas são desenhos próprios, não as capas originais.
